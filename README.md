## 🙋 个人概览 (About Me)

热衷于将尖端 AI 技术与真实垂直业务场景深度结合，聚焦于 **复杂业务流程的智能体化改造**、**Local-First 桌面与边缘端协同** 以及 **高可用微服务底座**。

- 🔭 **重点深耕方向：**
  - **垂直领域 AI 操作系统**：构建司法诉讼全生命周期的研判工作流引擎（40+ 智能体群协同与 PAE 反思闭环）
  - **MCP 生态与工具互联**：打造跨协议、多租户的企业级 Model Context Protocol (MCP) 聚合网关
  - **端侧与嵌入式 AI**：ESP32-S3/C5 语音交互模块、本地离线唤醒与超低延迟流式中枢
  - **AI-Native 产品与商业洞察**：育儿沟通智慧贩卖机、跨境电商数据洞察与商业元认知执行系统
- 💬 **欢迎交流：** AI 产品化工程落地 · MCP 协议工具链 · ESP32 嵌入式开发 · 垂直行业 RAG · 商业与育儿思考
- ⚡ **Fun Fact：** 一边写 Go 高并发网关和 ESP32 固件，一边搭建法律利息切片沙箱和育儿话术引擎 🤯
